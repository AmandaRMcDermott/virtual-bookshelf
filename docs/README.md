## Project Structure

The Virtual Bookshelf project is organized into the following main components:

1. **Web Application** - The front-end interface for the virtual bookshelf
   - HTML, CSS, and JavaScript files in the root and respective directories
   - Drag and drop functionality for organizing book spines

2. **Spine Detection Tools** - Python scripts for detecting book spines from images
   - Located in the `tools/spine_detection` directory
   - Includes multiple detection algorithms and utilities

3. **Integration** - Components for importing detected spines into the bookshelf
   - JavaScript integration modules in `js/integrate_spine_images.js`
   - Conversion utilities and data processing
